# Historias de Usuario

- **HU-01:** Como usuario del sistema, quiero iniciar sesión para acceder a las funcionalidades según mi cuenta.
- **HU-02:** Como responsable del almacén, quiero registrar productos para mantener actualizado el catálogo.
- **HU-03:** Como responsable del almacén, quiero registrar una compra a un proveedor para incrementar el stock de los productos recibidos.
- **HU-04:** Como responsable del almacén, quiero registrar una venta para descontar del stock los productos vendidos.
- **HU-05:** Como responsable del almacén, quiero consultar los productos con stock bajo para identificar cuáles necesito reponer.
