# Alcance del Proyecto

## 1. Descripción general

El proyecto consiste en el desarrollo de un sistema de gestión para un almacén de barrio, destinado a facilitar la administración de los productos, 
el control del stock, el registro de compras y ventas, y el seguimiento de los gastos del negocio.

## 2. Funcionalidades comprendidas

El sistema permitirá registrar y consultar productos, mantener actualizadas las existencias de mercadería, registrar las compras realizadas a proveedores 
y las ventas efectuadas, y consultar información relacionada con los movimientos y gastos del almacén.

Asimismo, contemplará mecanismos de autenticación para las operaciones que modifiquen información, de acuerdo con los requerimientos de seguridad establecidos.

## 3. Componentes comprendidos en el desarrollo

El desarrollo comprenderá:

- El diseño de la base de datos.
- La implementación de la lógica del sistema.
- Las interfaces necesarias para utilizar sus funcionalidades.
- Las pruebas correspondientes.

## 4. Exclusiones del alcance

Quedan fuera del alcance inicial las siguientes funcionalidades:

- Facturación electrónica.
- Integración con organismos fiscales.
- Conexión con sistemas de pago externos.
- Gestión de múltiples sucursales.
- Integración automática con sistemas de proveedores.

Estas funcionalidades podrían evaluarse en futuras versiones.

## 5. Consideraciones del proyecto

Dado que el proyecto se desarrolla con fines académicos y de portfolio, el funcionamiento del negocio se representará mediante un escenario ficticio
y datos de prueba, por ende no fue implementado o utilizado por un comercio real.
